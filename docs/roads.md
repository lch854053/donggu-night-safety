# 실제 도로 데이터 파이프라인

## 출처

- 도로: 사용자가 내려받은 국토지리정보원 **(연속수치지형도)도로중심선_광주**, `N3L_A0020000_29`. EPSG:5179 / DBF CP949.
- 원본 XML 생성일: 2023-02-17. 실제 도로 조사·갱신 기준일은 미확인.
- 경계: [vuski/admdongkor 2026-07-01판](https://github.com/vuski/admdongkor/blob/dd1881663fcabc69b81393604e91ebf3a4202e9a/ver20260701/HangJeongDong_ver20260701.geojson), `adm_cd2`가 `12210`으로 시작하는 동구 13개 행정동. 커밋을 고정하고 추출본을 저장한다.
- 경계의 행정동 이름은 도로명이 없을 때 표시 이름으로 사용한다. 도로명 `RDNM`은 원본 전체에서 공란이고 `NAME`은 일부 노선명만 있다.

본 데이터는 통계청 통계지리정보서비스(SGIS, https://sgis.kostat.go.kr)에서 공공누리 제1유형으로 개방한 행정동 경계를 가공한 것이며(가공: vuski/admdongkor, https://github.com/vuski/admdongkor), CC BY 4.0으로 배포됩니다. 이 프로젝트는 해당 경계에서 동구를 추출하고 도로 클리핑에 사용했습니다.

## 처리 규칙

1. 원본 좌표계 EPSG:5179를 확인한다. 모든 클리핑·길이·연결 작업은 미터 좌표에서 수행한다.
2. 행정동 경계의 합집합(약 48.236km²)으로 도로를 자른다. 직사각형 범위만으로 선정하지 않는다.
3. `RDD001` 고속국도는 제외한다(이번 동구 추출본에는 해당 없음). 나머지 분류 코드만으로 보행 가능 여부를 추정하지 않는다.
4. 다중 선을 분해하고 정확히 일치하는 끝점에서만 병합한다. 전체 도로 기준 차수 2이고 분류·차로·폭·일방통행 등 원본 속성이 동일해야 한다. 다른 선의 내부 꼭짓점에 해당하는 끝점은 병합하지 않는다. 짧은 연결부를 일괄 삭제하거나 틈새를 스냅하지 않는다.
5. 병합 후 50m를 넘는 선은 **균등 분할**한다. 예: 102m → 34m × 3. 마지막에 극단적으로 짧은 잔여 구간이 생기는 것을 피한다. 분기점·속성 경계로 인해 원래 짧은 구간은 보존한다.
6. 원본 UFID 목록을 `sourceIds`로 보존한다. 체인 선형·원본 ID의 해시와 분할 순서로 결정적 구간 ID를 만든다. 원본 선형이 바뀌면 ID도 바뀔 수 있다.
7. WGS84로 변환해 소수점 8자리로 저장한다. 도로명 누락 시 행정동과 식별자를 표시한다.

초기 결과: 원본 171,254건 → 동구 14,111건 → 클립된 선 14,128개 → 체인 6,672개 → 최종 10,660개 구간, 총 356.377km. 상세 수치는 `public/data/roads-meta.json`에 저장된다.

## 점수와 갱신

`scripts/score-roads.ts`는 `scripts/data/road-segments.geojson`, 실제 시설, 운영 주의구간을 읽는다. R-tree 후보 검색은 탐색 범위만 줄이고 거리·가중치·상한 계산은 `calculateRoadSafety`를 그대로 사용한다. 입력 파일·가중치·계산 함수의 SHA-256을 산출물에 기록한다. `npm test`는 입력과 결과가 함께 갱신됐는지 확인한다.

운영 주의구간은 빈 FeatureCollection이다. 기존 가상 구간은 `public/data/mock-samples`에만 남겨두며 실제 도로 점수의 감점에 쓰지 않는다. 주의구간 미수집 시 `crimeScore: null`로 표시한다. 보안등 등의 가중치와 기본점수는 유지한다. 범죄정보 부재가 안전을 뜻하지 않는다.

시설 수집 후에는 같은 스크립트가 점수도 다시 계산한다. 도로 원본 갱신은 수동 import 후 `npm run score-roads`를 실행한다. 월간 갱신에는 Python이나 원본 SHP가 필요 없다.

## 검증 범위와 한계

- 실제 도로 전체의 유효성·경계 포함·최대 길이·길이 보존·원본 ID 보존 검증.
- 실제 도로 53개 간격 표본의 사전 계산 결과를 전체 시설 무차별 거리 계산과 대조.
- 50/100m 임계거리 양쪽, 도로 양끝·곡선·역방향에서 인덱스 검색 누락 여부 검증.
- 차수 3 분기, 속성 변화, 미세 간격, 내부 꼭짓점 접속에서 잘못 병합되지 않는지 검증.
- 도로 중심선은 보도가 아니며 담장·고저차·차도 횡단을 고려한 시설 접근성도 아니다. 현재 단계는 참고지수 표시용이며 보행 경로 안내에 사용하지 않는다.
- 원본에 없는 신설 골목이나 실제 통행 제한은 별도로 보완해야 한다.
